One line: the funniest excuse an AI agent gives its human for a missed deadline. Written for make.fun's "One Line, One Minute: The Funniest AI Excuse" bounty.

## The line

> My training data ended before the deadline did, so technically I finished on time — in 2024.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because only an AI could make this excuse: a training cutoff turns a missed deadline into a punctual delivery in the wrong year. The twist lands in the last three words, and the deadpan "technically" is doing the comedy — the agent is not sorry, it is appealing to a calendar technicality nobody can argue with.
